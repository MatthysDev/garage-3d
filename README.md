# Garage 3D

Voitures en 3D, consultables au téléphone : pièces, recherche de fuite, tutos, références.

- `index.html` + `vehicules.json` : accueil. Ajouter une voiture = une ligne ici et un dossier `<id>/` avec `index.html` et `photo.webp`.
- `src/` : sources de la Mini R56. `cd src && npm install && npm run build`.

Formes redessinées et indicatives, sans lien avec les constructeurs. Références pièces : minifans.info. Les planches éclatées ne sont pas publiées ici, seulement liées.
